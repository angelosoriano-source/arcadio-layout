### Instalación en Linux

La instalación en distribuciones basadas en Linux (Ubuntu, Fedora, Arch, etc.) se realiza mediante un script automatizado que agrega Arcadio a la configuración de X11/Wayland, esto crea un archivo aparte que no afecta los archivos xkb de tu sistema.

Installation on Linux-based distributions (Ubuntu, Fedora, Arch, etc.) is done via an automated script that adds Arcadio to your X11/Wayland configuration. This creates a separate file that does not affect your system's existing xkb files.

**Pasos:**
1. Descarga el archivo llamado install.sh
   
2. Abre una terminal y navega hasta la carpeta donde este el archivo:
   Ejemplo: `cd /home/usuario/Downloads`

3. Dale permisos de ejecución al instalador:
   `chmod +x install.sh`
   
4. Ejecuta el script con privilegios de administrador:
   `sudo ./install.sh`
   
5. **¡Listo!** Al terminar cierra sesión y vuelve a entrar (o reinicia tu PC). Ve a la **Configuración de Teclado** de tu sistema, busca "Arcadio" y agrégalo segun te convenga, en formato ISO o ANSI.

### Desinstalación

**Pasos:**
1. Descarga el archivo llamado uninstall.sh
   
2. Abre una terminal y navega hasta la carpeta donde este el archivo:
   Ejemplo: `cd /home/usuario/Downloads`

3. Dale permisos de ejecución al instalador:
   `chmod +x uninstall.sh`
   
4. Ejecuta el script con privilegios de administrador:
   `sudo ./uninstall.sh`

5. Cierra sesion o reinicia tu pc, de esta manera ya no tendras Arcadio en tu sistema.

### Installation

**Steps:**

1. Download the file named install.sh.

2. Open a terminal and navigate to the folder where the file is located:
Example: `cd /home/user/Downloads`

3. Grant execution permissions to the installer:
`chmod +x install.sh`

4. Run the script with administrator privileges:
`sudo ./install.sh`

5. Done! Once finished, log out and log back in (or restart your PC). Go to your system's Keyboard Settings, search for "Arcadio," and add it as needed in either ISO or ANSI format.


### Uninstallation

**Steps:**

1. Download the file named uninstall.sh.

2. Open a terminal and navigate to the folder where the file is located:
Example: `cd /home/user/Downloads`

3. Grant execution permissions to the uninstaller:
`chmod +x uninstall.sh`

4. Run the script with administrator privileges:
`sudo ./uninstall.sh`

5. Log out or restart your PC; Arcadio will be completely removed from your system.
