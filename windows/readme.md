## Instalación

Spanish: Antes de instalar mira cual es tu tipo de teclado, sí es ANSI o ISO, ya que los simbolos y la letra ñ aparecen en lugares distintos segun la version, descomprime el .zip correspondiente, ejecuta el setup, y listo tendrias Arcadio instalado.

English: Before installing, check your keyboard type (ANSI or ISO), as the symbols and the letter (ñ) appears in different places depending on the version. Unzip the corresponding .zip file, run the setup, and you'll have Arcadio installed.
